# MASTER DEVELOPMENT PROMPT: Transform ParticaleStudio SVG Import into a Universal SVG-to-3D Particle Geometry Engine

## PROJECT OBJECTIVE

Upgrade the existing SVG Shape Import and 3D Particle Formation system in ParticaleStudio into a professional, advanced, procedural SVG-to-3D geometry generation engine.

This is an architectural upgrade to the existing application, NOT a separate application and NOT a replacement for the existing particle engine.

The goal is to allow users to import almost any valid SVG and transform it into many different types of editable, customizable, high-quality 3D particle formations.

A single SVG should be capable of generating dozens of different 3D structures using different geometry interpretation rules.

Preserve all existing functionality, interfaces, project compatibility, particle simulation, generators, animation, interactions and export systems.
