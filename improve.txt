# MASTER DEVELOPMENT PROMPT — Particle Studio Shape & Pattern Designer

## Project Context

You are working on my existing Particle Studio repository:

`littlecoder21/particalestudio`

Particle Studio already has:
- Canvas-based particle rendering.
- Procedural particle generators.
- SVG import and path sampling.
- Multiple SVG sources and morph sequences.
- Procedural WebGL2 shader generator.
- Shader masks and built-in shape definitions.
- Shader layers, effects and interactions.
- Particle and shader export systems.

I want to add a powerful, professional **Shape & Pattern Designer** as a new dedicated workspace.

This is NOT a simple shape picker, SVG uploader, or preset gallery.

I want users to CREATE their own shapes, patterns, geometry and mathematical formations visually, without manually writing SVG paths or JavaScript.

The result should be a versatile geometry creation environment that integrates with both the existing Particle Engine and Shader Engine.

- Vector paths.
- Bézier curves.
- Polygons.
- Multiple contours.
- Holes.
- Transformations.
- Pattern instances.
- Mathematical generator parameters.
- Sampling settings.
- Bounds.
- Optional animation parameters.

The exact TypeScript structure must be designed after inspecting the existing repository.

The unified geometry must support these operations:

1. Render as editable vector geometry.
2. Export as SVG.
3. Convert to particle positions.
4. Convert to shader mask data.
5. Animate between compatible shapes.
6. Use as an input to procedural shader generators.
7. Reuse geometry in pattern systems.

Do not create incompatible geometry formats for every editor.

Do not unnecessarily replace existing SVG source types. Build adapters or migrations where appropriate.
